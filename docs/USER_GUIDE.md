# DrumAI Studio 使用指南

## 1. 启动服务

### 后端

~~~bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -e ".[dev]"
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
~~~

运行真实转录还需要安装兼容版本的 DrumScript、CPU PyTorch/torchaudio，以及 FFmpeg/ffprobe。仅安装常规后端依赖时，上传和 API 可用，但分析任务会因可选引擎缺失而失败。

### 前端

~~~bash
cd frontend
npm install
npm run dev
~~~

打开 Vite 输出的本地地址。默认 API 地址为 http://127.0.0.1:8000；如需修改，设置 VITE_API_BASE_URL。

## 2. 上传与分析

工作区会自动读取最近保存的项目。刷新页面或重新打开工作区后，可在“恢复已保存项目”中选择已完成的项目继续编辑，也可重新接管仍在排队/运行中的分析任务。上次失败或尚未启动分析的项目可直接选择并重新运行；点击“刷新列表”可同步最新任务状态。

1. 选择 WAV、MP3、FLAC、M4A、OGG 或 AAC 音频。
2. 点击“上传并分析”，等待异步任务完成。
3. 结果会归一化为标准鼓事件，包括时间、鼓件、力度和速度/拍号信息。
4. 模型输出未经人工校对；请先播放原音频并检查鼓点，不要把自动转录结果当作准确率已验证的最终谱。

当前上传上限默认 100 MB，可通过后端环境变量 DRUMAI_MAX_UPLOAD_BYTES 调整。

## 3. 校对与节奏编辑

- 在事件列表中修改时间、鼓件或力度；也可以添加、删除事件。
- 时间轴按鼓件分轨显示，点击鼓点可跳转到音频对应位置。
- 使用量化网格（1/4、1/8、1/16、1/32）和强度滑杆修正节奏。先点击“预览量化”查看将移动的鼓点数量；调整网格或强度会使预览失效，需要重新预览。确认应用后才会写入历史版本，并同步更新标准事件和 MIDI。
- “撤销/重做”可恢复历史版本；新编辑会清除撤销位置之后的重做分支。

## 4. 练习播放

- 使用音频播放器播放、暂停和拖动进度。
- 点击“设为 A 点”和“设为 B 点”捕捉当前播放位置，再启用“A–B 循环”反复练习该段。
- 循环区间会在鼓点时间轴上高亮；“重置”恢复整首范围。
- 节拍器使用性能中的速度图，在速度变化处跟随 BPM 更新，并对小节起点使用更高音调提示。节拍器由浏览器 Web Audio 本地生成。

## 5. 导出

- **PDF**：应用使用 Verovio 开源制谱引擎对 MusicXML 进行专业排版，再生成矢量 PDF；可直接打印或分享。
- **MusicXML**：下载可编辑的鼓谱交换文件。可导入 MuseScore 等制谱软件继续修改音符、鼓件和版面；制谱软件也可用于进一步精细排版。
- **MIDI**：下载 GM 打击乐 MIDI，可用于 DAW、电子鼓音源或其他 MIDI 软件。

三种导出都读取最新标准鼓事件，因此会包含人工修改、量化、撤销和重做后的状态。

## 6. 运行边界

- 当前分析任务使用 FastAPI 进程内后台任务，适合单进程开发/验证；多 worker 或多实例部署前必须接入持久化任务队列和共享存储。
- 本地项目存储尚未提供面向公众的身份认证和多用户隔离。
- 请仅上传你有权处理的音频。仓库中的 MP3 冒烟测试只证明管线能运行，不代表模型转录准确率。


### 时间轴轨道筛选

- 在鼓点时间轴上方，可按鼓件勾选显示或隐藏轨道，也可一键全部显示/隐藏。
- 该筛选只改变时间轴的视觉呈现，不会删除事件、不改变 MIDI/MusicXML 导出，也不影响原音频播放；事件表始终保留完整事件。


### 批量修订鼓点

- 在事件表中勾选多个鼓点，或使用“全选”。
- 输入秒数偏移后选择“批量移动”：正数向后移动，负数向前移动；若任何事件会移到歌曲起点之前，整批操作会被拒绝，不会部分保存。
- “批量删除”会一次删除所选事件。
- 每次批量操作只创建一条撤销/重做历史记录，并同步更新 MIDI；所有选中事件会标记为人工修订。


### 复制与重复鼓点

- 在事件表中选中一个或多个鼓点，设置“重复间隔（秒）”和“重复次数”，然后点击“复制/重复所选”。
- 复制会保留鼓件、力度等属性，并按间隔向后生成新鼓点；原始事件不会被移动或覆盖。
- 重复次数为 1–16，间隔必须大于 0；若任一新鼓点超出歌曲时长，整次操作会被拒绝。
- 一次重复操作只创建一条历史记录，并同步标准事件与 MIDI；可使用撤销恢复。


### 按小节复制鼓点段落

- 在“小节段落复制”区域填写源小节和目标小节编号，点击“复制小节到目标位置”。
- 小节边界依据当前时间轴的 BPM 与拍号网格计算；复制时按源/目标小节长度映射每个鼓点的相对位置，保留段落节奏轮廓、鼓件、力度等属性。
- 原小节不会被移动或覆盖。粘贴后的事件作为人工修订写入标准鼓谱，并同步更新 MIDI。
- 源小节没有鼓点、目标位置超出歌曲时长或小节范围无效时，整次操作不会保存；成功操作只产生一条撤销历史记录。


时间轴支持鼠标框选：在空白区域按下并拖动可跨鼓件选择矩形范围内的事件；拖动已选中的鼓点可按时间偏移整体移动所选事件，操作作为一条历史记录并同步 MIDI。
